三、 从下载到配置：一步步激活Shadowrocket

第二步：获取并导入账号配置

这是核心步骤。假设您已从可靠服务商处获得了订阅链接（通常是一个URL）。 1. 打开Shadowrocket，应用主界面下方有“配置”标签页。 2. 点击右上角的“+”号，选择“从URL下载配置”。 3. 在弹出的框中粘贴您的订阅链接，点击“确定”。 4. Shadowrocket将自动下载并导入服务器节点列表。您可以在“首页”或“代理”页看到这些节点。

第三步：连接与测试

  1. 在“首页”或“代理”页面，从节点列表中选择一个您想连接的服务器（通常延迟越低越好）。
  2. 点击页面顶部的大型开关按钮，开启全局代理连接。您会看到开关变绿，并在屏幕顶部状态栏出现VPN图标。
  3. 打开浏览器，访问一个通常无法访问或用于测试的网站（如Google），检查是否成功。

第四步：进阶配置（规则模式）

全局代理并非总是最佳选择。Shadowrocket的精华在于其“规则模式”： 1. 在“配置”页面，确保已选中您导入的配置（左侧出现勾选）。 2. 点击配置名称右侧的“i”图标，进入详细设置。 3. 在“通用”部分，将“代理”模式改为“规则”。 4. 规则模式下，Shadowrocket会根据您配置文件内预置的规则（或您自定义的规则）智能判断：哪些流量走代理（如国外网站），哪些流量直连（如国内网站和本地服务）。这能实现速度与功能的完美平衡。

四、 常见问题与故障排除

  1. 连接成功但无法访问外网？

    • 在Shadowrocket的“全局路由”中尝试改为“代理”模式测试，如果代理模式可以，则是规则配置问题。

  2. 应用频繁断开连接？

    • 在“配置”页面，对您使用的配置左滑，选择“更新”。订阅链接有效时，会自动获取最新节点。

Surfboard 与 Shadowrocket 有什么区别？
两者都是 iOS 上的代理工具。Shadowrocket 功能更全面、更新更频繁，而 Surfboard 以轻量和快速见长。若只需简单分流与节点切换，Surfboard 足以满足日常使用。
V2RayN 的作用是什么？
V2RayN 是 V2Ray 的 Windows 图形客户端，提供节点管理、订阅导入、日志查看等功能。它支持多协议配置，并可与系统代理集成，是 Windows 用户最常用的代理管理工具之一。
Nekoray 支持节点批量更新吗？
支持。Nekoray 可通过订阅 URL 批量下载最新节点并替换旧节点。结合定时更新功能，可保持节点列表最新，减少手动维护和配置工作。
Hiddify Next 支持 Reality 吗？
支持。Hiddify Next 基于 sing-box 内核，可加载 Vless+Reality、Trojan+TLS 等高级协议配置。用户可直接导入机场订阅，无需手动修改复杂参数。
Hiddify Next 如何导入订阅？
打开 Hiddify Next，进入主页点击“添加订阅”，输入机场提供的链接后确认。应用会自动同步节点并分类显示，支持一键测速与规则模式切换。
Hiddify Next 如何设置用户带宽限制？
管理员可为每个用户设置独立带宽和流量配额，超出时可自动降速或阻止访问。这样可确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络效率和公平性。
Sing-box 的 DNS 模块如何工作？
Sing-box 内置 DNS 模块，支持 fake-ip 模式和纯直连模式。它可根据规则选择不同的上游 DNS 服务，从而实现国内外域名智能分流，减少访问延迟。
